# KillSuoji · Android 应用

KillSuoji 是一款 Android 工具应用，提供简洁的浅色薄荷绿界面与安全的 Root 状态检测流程。

## 当前版本
- 版本：**V1.1.0 beta**
- 平台：Android
- 下载页：https://3525808867a-dot.github.io/
- APK：[KillSuoji.apk](./KillSuoji.apk)

## 功能简介
- **主页**：显示应用工作状态与版本信息。
- **启动页**：检测 Root（su）权限状态，并提供执行入口。
- **按键提示**：连续按五次音量上键时显示提示。
- **安全设计**：仅管理应用自身状态，不强制结束其他应用或系统进程。
